# Face Mask Detection Using CNN

## Project Overview
This project focuses on detecting whether a person is wearing a face mask or not using a Convolutional Neural Network (CNN).

## Technologies Used
- Python
- Keras
- NumPy

## Model Architecture
Convolutional Neural Network (CNN)

## Project Implementation
The model is trained using image data to classify faces into two categories:
- With Mask
- Without Mask
