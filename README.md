# Face Mask Detection Using CNN

## Project Overview
This project focuses on detecting whether a person is wearing a face mask or not using a Convolutional Neural Network (CNN).

## Technologies Used
- Python
- Keras
- NumPy

## Dataset
The dataset is divided into two separate folders:
- **Training Dataset:** Used to train the CNN model.
- **Testing Dataset:** Used to evaluate the model's performance on unseen images.

The dataset contains two categories:
- With Mask
- Without Mask

## Model Architecture
Convolutional Neural Network (CNN).
